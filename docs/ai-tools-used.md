# תהליך הפיתוח ושימוש בכלי AI

במהלך פיתוח הפרויקט שילבתי את ChatGPT ו־Claude כחלק מתהליך העבודה ההנדסי, משלב ניתוח הדרישות והתכנון הארכיטקטוני ועד למימוש, לבדיקות ולתיעוד.

העבודה התבססה על גישת AI-Assisted Development, שבה כלי ה־AI מאיצים את תהליך הפיתוח ומסייעים בבחינת פתרונות, לצד בקרה הנדסית, הגדרת אילוצים ואימות התוצרים.

## אופן העבודה

### תכנון וארכיטקטורה

תחילה פירקתי את הדרישות לרכיבים ולשלבי מימוש, תוך בחינת חלופות ארכיטקטוניות, סיכונים והשלכות על אבטחה, תחזוקתיות והרחבה עתידית.

החלטות התכנון המרכזיות, בהן שימוש ב־Rule AST במקום SQL דינמי, קטלוג Metadata עסקי, גישה לקריאה בלבד לבסיס הנתונים ושילוב AI במודל Human-in-the-Loop, מתועדות ב־`docs/design-decisions.md`.

### פיתוח מונחה דרישות ואילוצים

העבודה מול כלי ה־AI התבצעה באמצעות הנחיות מובנות, שכללו הקשר ארכיטקטוני, דרישות פונקציונליות, קריטריוני קבלה ואילוצים טכניים.

הפיתוח התקדם בשלבים, תוך שמירה על הפרדת אחריות בין רכיבים, חוזי API, עקרונות אבטחה, Clean Code ועקביות בין שכבות המערכת.

### אימות ובקרת איכות

התוצרים נבחנו באמצעות שילוב של בדיקות אוטומטיות, בדיקות אינטגרציה, השוואת תוצאות המנוע לשאילתות SQL עצמאיות, בדיקות אבטחה ובדיקות ידניות של ממשק המשתמש.

כחלק מהתהליך הורצו 82 בדיקות QA אוטומטיות מקצה לקצה, לצד בחינה של מקרי קצה ותרחישי כשל.

ממצאים שהתגלו במהלך הבדיקות שימשו לשיפור המימוש ולבחינה מחודשת של החלטות לפי הצורך.

## שימוש משלים בכלי AI

- **ChatGPT:** ניתוח וחידוד דרישות, פירוק העבודה לשלבים, הגדרת קריטריוני איכות ובחינה ביקורתית של פתרונות והחלטות תכנון.
- **Claude:** עבודה מול בסיס הקוד, מימוש רכיבים בשכבות SQL, ‏.NET, ‏Python ו־Angular, סיוע בכתיבת בדיקות, ניתוח כשלים ותיעוד.

השילוב בין הכלים אפשר להפריד בין תכנון ובקרה לבין עבודת המימוש, ולבחון את התוצרים מכמה זוויות במקום להסתמך על כלי יחיד.

## אחריות הנדסית ושקיפות

השימוש ב־AI לא החליף את תהליך קבלת ההחלטות ההנדסיות, אלא השתלב בו.

לאורך הפיתוח בחנתי את הפתרונות שהוצעו, את התאמתם לדרישות ואת השיקולים הטכניים שמאחוריהם, תוך הסתמכות על תוצאות בדיקות והרצות בפועל.

הקפדתי להבחין בין יכולות שמומשו ואומתו לבין יכולות שעדיין דורשות השלמה או אימות נוסף. לדוגמה, אינטגרציית ה־LLM החיצוני מומשה ונבדקה, אך תרחיש המלצה מלא מקצה לקצה לא הושלם בסביבת הפיתוח, כפי שמתועד ב־README.

מבחינתי, הערך בשימוש בכלי AI אינו רק במהירות כתיבת הקוד, אלא ביכולת להוביל באמצעותם תהליך פיתוח מסודר — מתכנון וקבלת החלטות ועד למימוש, אימות ושיפור מתמשך.
